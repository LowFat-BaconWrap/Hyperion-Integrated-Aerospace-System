# Design Decisions
I think the reasons WHY I do certain things would be useful to clear up confusion and make it easier to alter things to anyone making edits.

## Hardware Decisions
Raspberry Pi 4:
- High computational power
- Highly compact and portable

Arduino nano:
- High computational power
- High quality analog and digital control
- Separates the control segment from high-level computation

## Software Decisions
Python:
- Easy, lightweight, highly compatible with APIs and desired libraries
